# 01. 제품 명세

## 한 줄 정의

**갑빠왕**: 푸쉬업을 할수록 내 캐릭터의 가슴(갑빠)이 진화하는 운동 트래커.

## 핵심 가치 제안

운동 기록 앱은 많지만 **꾸준히 하게 만드는** 앱은 적다. 갑빠왕은:

1. **시각적 보상** — 캐릭터가 누적 푸쉬업에 따라 9단계 진화 (마른 체형 → 갑빠왕)
2. **자동 카운팅** — 카메라를 벽에 두고 엎드리면 비전 모델이 알아서 셈
3. **과학 기반 진단** — 1회 최고기록(1RM 개념)으로 객관적 체력 측정
4. **공유 가능한 성취** — 레벨업 시 카카오톡으로 자랑 카드 공유

## 페르소나

- **주 타깃**: 20–35세 남성, 헬스 입문~중급
- **상황**: 집에서 운동, 홈트, 매일 정량적 기록 원함
- **고통점**: 운동 기록 앱이 너무 복잡함 / 카운트하기 귀찮음 / 동기부여 부족

## 캐릭터 진화 단계 (단일 진실 공급원)

```
1단계: 마른 체형      누적 0개~
2단계: 약간 다듬어진   누적 100개~
3단계: 보통 운동인     누적 500개~
4단계: 단단한 체형     누적 2,000개~
5단계: 근육질         누적 5,000개~
6단계: 대흉근 부각     누적 10,000개~
7단계: 갑빠 형태 완성  누적 25,000개~
8단계: 보디빌더형      누적 50,000개~
9단계: 갑빠왕 (최종)   누적 100,000개~
```

이 임계값(stageBoundaries)은 클라이언트와 서버 양쪽에서 **동일하게** 사용해야 합니다.

## MVP 기능 목록

### Tier 1 (출시 필수)
- [ ] 인증: 카카오 / 구글 / 이메일 로그인
- [ ] 온보딩: 닉네임, 목표(자유 운동/체중감량/근육증진), 신체정보(선택)
- [ ] 홈: 캐릭터 상태, 진화 진행도, 1회 최고/누적/연속, "운동 시작"
- [ ] 운동 시작: 모드 선택(자유 / 세트별 목표 / 갑빠 챌린지)
- [ ] 운동 진행: 비전 카운터 + 수동 카운트 백업 + 세트 휴식
- [ ] 결과: 세트별 횟수, 캐릭터 진화 진행도, PR 갱신 시 축하
- [ ] 레벨업: 9단계까지 모두 동적 표시 + 카카오 공유 카드
- [ ] 기록: 1회 최고기록(히스토리), 캘린더(히트맵), 통계(차트)
- [ ] 캐릭터: 9단계 진화 로드맵
- [ ] 알림: PR 갱신, 연속운동 위기, 리마인더
- [ ] 설정: 알림 토글, 음성 카운트, 단위, 계정

### Tier 2 (출시 후 1~2개월)
- [ ] 챌린지: 7일 / 30일 / 100개 / 1000개 등
- [ ] 프리미엄 구독: AI 코칭(자세 피드백), 고급 통계, 캐릭터 커스터마이징
- [ ] 카카오 공유 카드 이미지 저장

### Tier 3 (이후)
- [ ] 친구 / 랭킹 / 챌린지 함께하기
- [ ] 다른 운동 종류 (스쿼트, 윗몸일으키기)
- [ ] 위젯, 워치 연동

## 디자인 원칙

1. **다크 + 옐로우**: 앱 정체성. 배경은 거의 검정(#0a0a12), 액션은 옐로우(#ffc400)
2. **숫자에 단위 명시**: "76" 대신 "76회"
3. **캐릭터가 주인공**: 홈/결과/레벨업/캐릭터 화면에서 캐릭터를 가장 크게
4. **애니메이션은 보상의 순간에**: 레벨업, PR 갱신, 운동 완료 시에만 화려하게
5. **탭 화면엔 뒤로가기 없음**: 홈/기록/챌린지/설정은 BottomNav만

## 비기능 요구사항

- **오프라인 우선**: 운동 진행 중 네트워크 끊겨도 카운팅/저장 동작
- **로컬 캐시 → 서버 동기화**: Room DB 로컬 저장 후 백그라운드에서 Supabase 동기화
- **개인정보**: 신체 정보는 옵션. 카메라 영상은 절대 서버 전송 안 함 (온디바이스 추론)
